# Giải cứu xưởng máy — MLN122 Pixel Boss Rush

Trò chơi tương tác thời gian thực 2D Pixel Boss Rush môn Kinh tế chính trị Mác – Lênin (Chương 3: Giá trị thặng dư & Tích lũy tư bản).

- **4 Phase Boss · 40 Câu hỏi**: Điều khiển nhân vật bằng `WASD` / Phím mũi tên / D-Pad cảm ứng, thu thập trạm năng lượng `[?]` và trả lời đúng 6 câu hỏi mỗi Phase để hạ gục Trùm Tư Bản.
- **Hỗ trợ 2 chế độ**:
  - **Đua Top cả lớp (Realtime Multiplayer QR)**: Quét mã QR hoặc nhập mã phòng 6 ký tự trên mọi thiết bị (4G/5G/Wi-Fi).
  - **Solo Pixel Boss Rush**: Chơi tự do ngay trên trình duyệt không cần mã phòng.
